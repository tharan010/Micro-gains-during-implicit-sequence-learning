Micro-offline gains do not drive implicit motor sequence learning
Tharan Suresh, Michael V Freedberg, Sara J Hussain

Contents:
SRTT_master_data.csv: Raw input: one row per keypress (Acquisition 1-14 & Retention 1-7).
summary_SRTT_master_data.csv: Input for the RT models: per-subject × block mean RT.
SRTT_PDP.csv: Input for the PDP analysis (inclusion/exclusion scores; group 1 = Sequence, 2 = No-Sequence).
master_analysis_code.py: Computes all metrics from the master data, writes the 6 CSVs that iSRTT_stats.Rmd takes as input for statistical analysis, and generates the figures.
iSRTT_stats.Rmd: All statistics (mixed models, t-tests, correlations, PDP).

Requirements:
Python 3 with pandas, numpy, scipy, matplotlib, seaborn
R with tidyverse, lme4, lmerTest, emmeans

To reproduce:
Put all five files in one folder.
2. Run python master_analysis_code.py first. It reads the three input CSVs and writes the following
	2a. Figures: Figure_2.pdf, Figure_3.pdf,
	2b. Supplemental_Figure_1.pdf, Supplemental_Figure_2.pdf

3. Run iSRTT_stats.Rmd, it takes the CSV files generated by master_analysis_code.py, see below:
	3a. summary_SRTT_speed_data.csv
	3b. SRTT_bonstrup_speed_seq2seq_all.csv
	3c. SRTT_skill_metric_all.csv
	3d. SRTT_skill_speed_metric_all.csv
	3e. SRTT_seq2seq_summed_gains_all.csv
	3f. SRTT_acquisition_gain_skill_correlations.csv
